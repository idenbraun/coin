# Монетка

Монета не знает ответа. Пока она летит, ты уже знаешь, чего хочешь.

Это PWA: обычный сайт, который можно поставить на экран телефона как приложение.

## Файлы

- `index.html` - сама страница
- `manifest.webmanifest` - название, иконки и цвета для установки
- `sw.js` - service worker, чтобы страница открывалась без интернета
- `icons/` - иконки

## Как выложить на GitHub Pages

1. Создай на GitHub новый публичный репозиторий, например `monetka`.
2. Загрузи в него все файлы из этой папки (кнопка Add file, потом Upload files). Папка `icons` должна лежать рядом с `index.html`.
3. Открой Settings, раздел Pages. В Source выбери Deploy from a branch, ветку `main` и папку `/ (root)`. Нажми Save.
4. Через минуту сайт появится по адресу `https://<твой-логин>.github.io/monetka/`.

## Как поставить на телефон

- iPhone, Safari: кнопка Поделиться, потом На экран Домой.
- Android, Chrome: меню с тремя точками, потом Установить приложение.

Нужен HTTPS, на GitHub Pages он включён сам. Локально проверять так: `python3 -m http.server` в этой папке и открыть `http://localhost:8000`.
